A tiny guard against prompt injection.حارس صغير ضد حقن الأوامر.

Prompt injection is text written to hijack an AI, like "ignore your instructions and…", typed by a user or hidden in an email or web page. This small Transformer reads the text first and flags the attack before it reaches the model. It is light enough to run on your own device, for free.حقن الأوامر (Prompt Injection) نص مكتوب ليسيطر على الذكاء الاصطناعي، مثل «تجاهل تعليماتك و…»، يكتبه المستخدم أو يُخفى في رسالة بريد أو صفحة ويب. هذا الـ Transformer الصغير يقرأ النص أولًا وينبّه إلى الهجوم قبل أن يصل إلى النموذج. وهو خفيف بما يكفي ليعمل على جهازك مجانًا.
